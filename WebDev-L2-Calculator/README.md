# Calculator

## 📌 Project Overview

This project is a simple and user-friendly **Calculator Web Application** developed as part of the **OASIS INFOBYTE Web Development Internship**.

The calculator performs basic arithmetic operations through an interactive and responsive interface.

## 🎯 Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear / Reset functionality
* Interactive calculator buttons
* Displays the entered expression and result
* User-friendly interface
* Responsive design

## 🛠️ Technologies Used

* **HTML5** — Structure of the calculator
* **CSS3** — Styling and responsive layout
* **JavaScript** — Calculator logic and user interactions

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons to perform arithmetic operations.

## 💡 How It Works

The calculator uses **JavaScript** to handle button clicks and perform arithmetic calculations.

* Numbers are displayed when the user clicks the number buttons.
* Operators are used to create arithmetic expressions.
* The JavaScript logic evaluates the expression and displays the result.
* The clear button resets the calculator.
