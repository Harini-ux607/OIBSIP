# 🔐 User Authentication System

A simple **User Authentication System** developed as part of my **OASIS INFOBYTE Web Development Internship**.

The project provides a basic authentication flow where users can register, log in, and access a protected page after successful authentication.

## 🚀 Features

* 📝 User Registration
* 🔑 User Login
* 🔒 Authentication Validation
* 👤 Protected User Page
* 🚪 Logout Functionality
* 📱 Responsive Design
* ⚠️ Form Validation and Error Messages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 📂 Project Structure

```text
user-authentication/
│
├── index.html
├── login.html
├── register.html
├── home.html
├── style.css
└── script.js
```

## ⚙️ How It Works

1. The user creates an account using the registration form.
2. The registration details are stored in the browser's Local Storage.
3. The user enters their email/username and password on the login page.
4. JavaScript validates the entered credentials.
5. If the credentials are correct, the user is redirected to the protected home page.
6. The user can log out using the Logout button.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Register a new account.
5. Log in using the registered credentials.
